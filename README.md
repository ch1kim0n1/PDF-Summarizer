# PDF-Summarizer

Resperatory for the Hugging Face's NLP Model that can read books and answer questions accordingly.

# Ideas
* process pdf files and give a responce to a prompt of a user
* create website wrapper around it (React)
* AI must be able to cover 100s of pages -> increase speed
* AI that recognize a book and then answers any follow up questions about it.
* Chatbot feature
* You need to pick a book from a library/dropdown of books that are available. (library API)
* If not available, then make a request to make it. (submission form)
